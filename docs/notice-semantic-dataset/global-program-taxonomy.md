# 해외·국제 프로그램 실제 공지 기반 분류 v1

## 수집 범위

- 명지대학교 공식 도메인에 공개된 2023~2026년 공지와 국제교류 안내를 우선 조사했다.
- `WELL`, `WEST`, `K-Move`, `WSP`, `SAF`, `Erasmus+`, 교환·방문학생, 복수학위,
  미래에셋 해외교환 장학, ASEM-DUO, GKS 우수교환, 닛켄세, 해외 단기연수,
  해외봉사, SSPU, 해외취업 프로그램을 확인했다.
- 확인한 대표 원문·공식 안내 35건은 `global-program-source-catalog-v1.jsonl`에 URL과 함께 보존한다.
- 2026-08-01 운영 DB의 활성 공지 2,671건을 읽기 전용으로 전수 조사했다. 해외·국제 후보 제목
  151건을 검토해 반복 고유명과 구체 표현을 반영하고, 안전 안내·국내 인턴·교직원 채용처럼
  단어만 겹치는 문서는 경계 사례로 제외했다.

## 분류 원칙

1. 화면의 `해외·국제 프로그램`은 모든 하위 프로그램을 받는 상위 구독 Topic이다.
2. 고유 프로그램을 선택할 수 있도록 WELL, WEST, WSP, K-Move, SAF는 별도 Topic으로 둔다.
3. 공지에는 가장 구체적인 직접 Topic만 판정하고 부모 Topic은 매칭용으로 확장한다.
4. WELL·WEST처럼 취업과 국제프로그램 성격이 겹치는 공지는 복수 Topic을 허용한다.
5. `해외` 단독은 별칭으로 쓰지 않는다. 해외기업 뉴스, 해외 학술행사 등까지 과도하게 포함하기 때문이다.
6. `WELL`, `WEST`, `WSP`, `SAF`는 영문 단어 내부가 아닌 독립 토큰일 때만 일치시킨다.
7. MJU International Summer School은 주로 해외 학생을 국내로 초청하는 프로그램이므로
   국내 학생 대상 `해외 단기연수`와 자동으로 동일시하지 않는다.

## 정기성

- WEST: 통상 상·하반기 모집형으로 관찰한다.
- 해외 단기연수: 하계·동계 방학 전에 반복 공지된다.
- 해외봉사: 하계·동계 선발, 합격, 사전교육 공지가 한 묶음으로 반복된다.
- 교환·방문학생: 다음 학기 파견을 위해 학기보다 앞서 선발한다.
- WELL·K-Move·해외취업 프로그램: 외부 사업 일정에 따라 수시·추가모집이 발생한다.
- 전공학문연계 해외문화탐방: 하계 모집·합격 공지가 반복된다.
- 해외연수 장학: 지역 장학재단별 모집이 수시로 발생해 연수와 장학 Topic을 함께 부여할 수 있다.

정기성은 추천 노출 시기를 결정하는 참고값이며, 실제 노출은 최신 공지와 마감일을 우선한다.
