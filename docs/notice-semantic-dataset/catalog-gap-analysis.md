# Topic Catalog gap 분석 v1

## 현재 범위

Catalog v3는 졸업, 수강신청, 휴·복학, 신·편입학, 취업지원, 국가근로, 기숙사와 해외·국제
프로그램을 포함한 34개 Topic과 122개 별칭을 가진다. 자동완성·Topic 알림의 현재 지원 범위는
완성됐지만 학교 공지 전체를 분류하려면 아래 일반 학사 영역을 다음 버전에서 확장해야 한다.

## 별칭 보완 후보

- `EMPLOYMENT_SUPPORT`에 일반 `취업`을 무조건 추가하면 직원 채용·졸업 요건 본문으로 오탐한다.
  제목 카테고리 또는 `프로그램`, `컨설팅`, `상담` 같은 문맥 규칙과 함께 사용해야 한다.
- `NEW_TRANSFER_ADMISSION`의 `신입생`/`편입생` 별칭은 Topic보다 Audience 표현인 경우가 많다.
  입학·모집·학번·오리엔테이션 문맥 없이 단독 Topic으로 사용하지 않아야 한다.
- `GRADUATION`의 일반 `졸업` 별칭은 본문 전체에 적용하지 말고 제목 또는 핵심 목적 문장으로 제한해야 한다.
- `LEAVE_RETURN`의 `휴학`/`복학`도 자격 조건이나 예외 설명에 단순 등장할 수 있으므로 본문 전체 매칭은 피한다.

새 Topic은 데이터셋의 양성·음성 표본과 최소 합격 기준이 준비된 뒤 기존 Catalog 버전을 올려 추가한다.
